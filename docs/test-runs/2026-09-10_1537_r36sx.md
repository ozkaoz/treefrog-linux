# Test run: r36sx — 2026-09-10 15:37 (test #11: k5 = init PROPIO FASE F)

## Contexto — FASE F iniciada (§25: initramfs mínimo propio → rootfs TreeFrog)

k4 (test #10) = golden: kernel nuestro con initramfs STOCK embebido bootea el
sistema completo (icube→rkgame→zhijack→FrogUI). Este test sustituye el init
stock por **NUESTRO initramfs** (`scripts/build-initramfs.sh`, 371 archivos):

- `linuxrc` propio (`rootfs/treefrog/linuxrc`): devtmpfs/proc/sys/tmp → hcdaemon
  (AMPRPC al AVP stock) → mdev + montar SD en /mnt/sdcard (bind-mounts como
  S99app) → cubevol (input gpio→/tmp/joy_key, desde la SD) → CPU governor
  performance → TF_DEVICE env → **loop picoarch+FrogUI directo** con el mismo
  protocolo `/tmp/frogui_launch.txt` de zhijack.sh (standalone/juegos).
- Reutilizados del firmware (ya presentes en la SD del usuario): busybox, lib/,
  hcdaemon, hotplug_helper. Eliminados: init/inittab/rcS/S-scripts stock,
  icube/rkgame/zhijack ya no participan.
- Blueprint documentado: S10mdev+S41hcdaemon+S99app (extracto R30) +
  cubegm/zhijack.sh (receta probada tests #9/#10).
