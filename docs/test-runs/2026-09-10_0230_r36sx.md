## Criterio de éxito

1. **Expectativa ideal:** boot completo (logo hcboot/AVP) → nuestro kernel → init stock
   → zhijack → FrogUI con **input funcional** (joydev presente → `/dev/input/js0` →
   cubevol → `/tmp/joy_key` → picoarch). Registro en `log.txt`.
2. **Expectativa mínima (milestone):** el kernel nuestro arranca y el sistema llega al
   menú navegable (era el único fallo conocido del test #1: input muerto sin joydev).

## Diagnóstico si vuelve a fallar

- **Si `Please insert TF card` persiste:** la causa es la geometría FAT/MBR actual
  (offset 1 MB, clúster 32 KB, activa=False). Siguiente acción: respaldar, reformatear
  Física FAT32 clúster 4K + marca activa (con admin) y restaurar el sistema completo.
- **Si logo eterno sin input:** revisar `/proc/bus/input/devices` desde el rootfs stock
  (getevent/avpconsole) — joydev ya está built-in.
- **Si boot pero congelado a mitad:** drivers/config (comparar dmesg si hay serial).
